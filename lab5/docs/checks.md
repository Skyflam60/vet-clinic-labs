# Проверка работы

Страница проверена автоматически в Chromium. Также проверен синтаксис трёх файлов JavaScript.

| Проверка | Результат |
|---|---|
| Начальная загрузка | 6 приёмов и 3 животных — выполнено |
| Выбор статуса | 2 завершённых приёма — выполнено |
| Пустой поиск | Таблица скрыта, счётчик 0 — выполнено |
| Пустая форма | Подсказка, строка не добавлена — выполнено |
| Добавление и безопасный вывод | 7 строк, введённое HTML показано текстом — выполнено |
| Завершение | Класс done и кнопка Вернуть — выполнено |
| Удаление | Снова 6 строк — выполнено |
| Медленная загрузка | Сообщение и недоступная кнопка — выполнено |
| Сбой сервера | Красное сообщение 500 — выполнено |
| Нет сети | Сообщение о связи — выполнено |
| Восстановление | Список снова загружен — выполнено |
| Неверный адрес | Сообщение 404 — выполнено |
| Ошибки JavaScript | Нет необработанных ошибок — выполнено |

Для ручной проверки откройте консоль браузера:

```js
MockApi.setDelay(2000, 3000)
MockApi.setErrorRate(1)
MockApi.setNetworkDown(true)
```

Проверяйте эти режимы по одному. Вернуть обычный режим:

```js
MockApi.setDelay(300, 800)
MockApi.setErrorRate(0)
MockApi.setNetworkDown(false)
```

Для проверки 404 временно замените /api/appointments в loadAppointments на /api/wrong, затем верните правильный адрес.

Настоящие снимки страницы сохранены в ZIP-комплекте: список, изменение списка и ошибка. В GitHub изображения пока не загружены.
