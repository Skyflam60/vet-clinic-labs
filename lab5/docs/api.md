# Запросы учебного сервера

| Метод | Адрес | Тело запроса | Ответ | Ошибки |
|---|---|---|---|---|
| GET | /api/appointments?status=&q= | Нет | 200, массив приёмов | 500 при включённом сбое |
| GET | /api/animals | Нет | 200, массив животных | 500 при включённом сбое |

Неизвестный адрес возвращает 404. При отключённой сети запрос завершается исключением без кода ответа. Пустой поиск возвращает все записи. Статусы: scheduled — запланирован, done — завершён, cancelled — отменён.

Пример приёма: id, animal_id, title (причина), doctor (врач), date (дата и время), status. Запросы POST и DELETE не добавлялись: в основной части задания изменение списка выполняется в браузере.
