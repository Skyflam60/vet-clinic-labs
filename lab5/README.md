# Лабораторная работа №5
## Реализация клиентской логики
Выполнили: Парфенова Екатерина, Елена Ярмуш

## Цель работы

Научиться обрабатывать действия пользователя, изменять страницу и загружать данные с помощью JavaScript.

## Что сделано

Сделана страница записи на приём по макетам ЛР №4. Есть форма, таблица, поиск и выбор статуса. Используются шесть приёмов и три животных.

| Событие | Что происходит |
|---|---|
| Отправка формы | Проверяются поля и добавляется строка без перезагрузки |
| Нажатие кнопки | Загрузка списка, завершение приёма или удаление строки |
| Выбор статуса | Список загружается с выбранным фильтром |
| Ввод поиска | Загружается список подходящих приёмов |

Строки создаются через document.createElement, удаляются через remove. Текст записывается через textContent. У строки меняются класс done и атрибут data-id, у кнопки — подпись и title. Счётчик обновляется после изменения списка.

Данные загружаются через fetch и await. Проверяется response.ok. Во время загрузки кнопка недоступна, при ошибке появляется сообщение, при пустом результате таблица скрыта. Ответ на старый поиск не заменяет результат нового поиска.

Добавление, завершение и удаление выполняются только на странице. Нажатие «Загрузить с сервера» возвращает исходные учебные данные. Отмена реальной записи на сервере здесь не реализуется.

## Вывод

Реализованы обработка событий, изменение элементов страницы и загрузка данных без перезагрузки.
