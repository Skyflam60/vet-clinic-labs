## Цель работы

Создать серверную часть на PHP, настроить маршруты и обработку запросов.

## Предметная область

| Что определено | Наш вариант |
|---|---|
| Основная сущность | Приём, appointment / appointments |
| Связанная сущность | Животное, animal / animals |
| Поля приёма | id, animal_id, title, doctor, date, status |
| Фильтр | status: scheduled, done, cancelled |
| Поля животного | id, name, owner |

Названия страниц, поля и данные относятся к ветеринарной клинике. Подготовлены шесть приёмов и три животных. При просмотре животного показываются его приёмы.

## Структура проекта

| Каталог | Назначение |
|---|---|
| src/public | Точка входа и оформление страниц |
| src/app/Core | Маршрутизатор |
| src/app/Controllers | Контроллеры |
| src/app/Models | Чтение и сохранение данных |
| src/app/Views | Шаблоны страниц |
| src/routes | Список маршрутов |
| src/config | Название системы |
| src/storage | Файлы с приёмами и животными |


## Маршрутизация и контроллеры

Все запросы проходят через public/index.php. Маршрутизатор сравнивает метод и адрес, вызывает контроллер и передаёт номер из адреса. Если маршрут или запись не найдены, возвращается 404.

- HomeController показывает главную и количество записей.
- AppointmentController показывает список, отдельный приём и форму, проверяет и сохраняет данные.
- AnimalController показывает список животных и карточку с приёмами.

После сохранения формы выполняется перенаправление 302. При ошибке возвращается форма с кодом 422, введёнными значениями и подсказками. Пользовательские данные выводятся через e().
