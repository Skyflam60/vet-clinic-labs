# Проверка приложения

PHP в среде подготовки отсутствует. Поэтому ниже приведены ожидаемые результаты, а не отчёт об успешно выполненном запуске. Серверные страницы и сохранение файла нужно проверить после установки PHP. Скриншоты ЛР №6 пока не сделаны.

| Запрос или действие | Ожидаемый результат |
|---|---|
| GET / | 200, четыре показателя |
| GET /appointments | 200, шесть исходных приёмов |
| GET /appointments?status=done | 200, два завершённых приёма |
| GET /appointments/3 | 200, приём и ссылка на животное |
| GET /appointments/999 | 404 |
| GET /appointments/create | 200, форма |
| Пустая форма | 422, подсказки и сохранённые поля |
| Правильная форма | 302, затем 200, запись в списке и JSON |
| GET /animals | 200, три животных |
| GET /animals/2 | 200, животное и его приёмы |
| GET /nonexistent | 404 |
| POST /animals | 404 |
| GET /tasks и GET /projects | 404, старые адреса не используются |

В каталоге lab6/src можно проверить ответы командами:

```sh
curl -i http://localhost:8000/appointments
curl -i http://localhost:8000/appointments/999
curl -i -X POST -d "title=" http://localhost:8000/appointments
```

После создания приёма проверьте storage/appointments.json. Обновление списка после перенаправления не должно повторно создавать запись. Перед испытаниями можно сохранить копию JSON и после проверки вернуть её.

Проверьте также, что текст с символами < и > выводится как текст. Сделайте снимки главной, списка,просмотра, формы с ошибкой, страницы 404 и вкладки Network.
