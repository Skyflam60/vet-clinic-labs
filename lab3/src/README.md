# Структура проекта

| Каталог | Назначение |
|---|---|
| frontend | Страницы, оформление и элементы интерфейса |
| backend/controllers | Приём запросов |
| backend/services | Обработка действий пользователей |
| backend/repositories | Работа с базой данных |
| backend/models | Объекты предметной области |
| backend/routes | Маршруты API |
| database | Файлы базы данных |
| docs | Документация |

Пока подготовлена только структура. Оставшийся пустой каталог backend/workers в новой схеме не используется.
