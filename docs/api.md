# Описание API

Веб-интерфейс отправляет запросы серверу. Сервер проверяет пользователя, обрабатывает данные и возвращает результат.

| Метод | Адрес | Назначение | Роль |
|---|---|---|---|
| POST | /api/auth/login | Вход в систему | Все |
| POST | /api/auth/logout | Выход | Все |
| GET | /api/owners | Список владельцев | Администратор |
| POST | /api/owners | Регистрация владельца | Администратор |
| POST | /api/animals | Добавление животного | Администратор |
| GET | /api/animals?ownerId= | Животные владельца | Администратор, врач, владелец |
| GET | /api/animals/{id} | Карточка животного | Администратор, врач, владелец |
| POST | /api/appointments | Запись на приём | Администратор |
| PUT | /api/appointments/{id} | Перенос приёма | Администратор |
| DELETE | /api/appointments/{id} | Отмена приёма | Администратор |
| GET | /api/appointments?doctorId=&date= | Расписание | Врач, администратор |
| GET | /api/animals/{id}/history | История лечения | Врач, владелец |
| POST | /api/medical-records | Создание медицинской записи | Врач |
| PUT | /api/medical-records/{id} | Изменение медицинской записи | Врач |
| GET | /api/reports | Отчёты | Руководитель |

Владелец видит только своих животных. Врач просматривает своё расписание. Администратор не создаёт медицинские записи. Отмена приёма не удаляет историю лечения.

## Пример записи на приём

POST /api/appointments

```json
{
  "animalId": 15,
  "doctorId": 7,
  "date": "2026-10-05",
  "time": "14:30",
  "reason": "Плановый осмотр"
}
```

Ответ:

```json
{
  "id": 42,
  "message": "Приём успешно создан"
}
```

Если время занято, система предлагает выбрать другое. Если письмо не удалось отправить, приём остаётся сохранённым.
