# Лабораторная работа №7
## Проектирование REST API

## Цель работы

Сделать запросы для получения и изменения данных ветеринарной клиники.

## Ресурсы

| Ресурс | Адрес | Данные |
|---|---|---|
| Приёмы | /api/appointments | Животное, причина, врач, дата, статус |
| Животные | /api/animals | Кличка и номер владельца |
| Владельцы | /api/owners | ФИО, телефон, электронная почта |

Для каждого ресурса есть получение списка и одной записи, создание, изменение и удаление. GET возвращает данные, POST создаёт запись, PUT и PATCH меняют присланные поля, DELETE удаляет запись. Как в учебном задании, PUT здесь не заменяет запись целиком.

## Что сделано

За основу взяты структура и данные ЛР №6. Маршрутизатор дополнен методами PUT, PATCH, DELETE и ответом 405. Модели читают и сохраняют JSON. Для трёх ресурсов созданы отдельные контроллеры.

Приём связан с животным, животное — с владельцем. Нельзя удалить животное с приёмами или владельца с животными: возвращается 409. Для приёмов есть фильтр по статусу и животному, а также поиск по причине обращения. Неизвестные поля, включая переданный id, не сохраняются.


## Запуск


```sh
php -S localhost:8000 -t public
```

## Примеры запросов и ответов

| Запрос | Пример ответа | Код |
|---|---|---|
| GET /api/owners | [{"id":1,"name":"Иванов И.И.","phone":"+79000000001","email":"ivanov@example.org"}] | 200 |
| GET /api/animals/1 | {"id":1,"name":"Рекс","owner_id":1} | 200 |
| POST /api/owners с {"name":"Иванов Иван","phone":"+79000000009"} | {"name":"Иванов Иван","phone":"+79000000009","email":"","id":4} | 201 |
| PATCH /api/animals/1 с {"name":"Рексик"} | {"id":1,"name":"Рексик","owner_id":1} | 200 |
| DELETE /api/appointments/1 | Без тела | 204 |


[Описание всех запросов](docs/api.md) · [Проверка API](docs/testing.md).

Подготовлено API для трёх ресурсов. Реализованы основные операции, проверка полей и единый формат ошибок. Данные хранятся в JSON-файлах.
