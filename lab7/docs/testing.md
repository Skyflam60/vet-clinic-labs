# Проверка API

Проверки запускаются после старта сервера:

```sh
php tests/check.php
```

Сценарий выполняет пять операций для каждого ресурса, проверяет коды 400, 404, 405, 409, 422, заголовки Location и Allow, пустой ответ 204, фильтр и поиск. Фактические коды записываются в этот файл, полный вывод — в docs/requests.txt.

До выполнения сценария фактические коды не заполнены. Успешный результат пока не подтверждён.

Запускать на отдельном учебном сервере с данными из этого каталога. Во время проверки не менять данные другими запросами. Исходные JSON-файлы восстанавливаются в конце сценария.

Проверка также запускается в GitHub Actions. Файлы testing.md и requests.txt сохраняются в архиве lab7-results соответствующего запуска, но не записываются автоматически обратно в репозиторий.

Для снимков экрана выполните запросы из docs/api.md через Postman или curl. Нужны снимки успешных операций и ошибок с видимыми методом, адресом и кодом ответа. Снимки в комплект пока не добавлены.
